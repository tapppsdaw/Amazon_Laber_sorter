# Amazon_Laber_sorter
A desktop tool for Amazon FBA sellers. Automatically sorts, groups, and renames mixed FBA box labels (PDF) by SKU and Warehouse. Supports custom Chinese annotations to prevent labeling errors in factories.
专治 FBA 标签顺序混乱的桌面神器！
每次从亚马逊后台导出一批包含多个 SKU 的货件，结果被系统强行拆分到 5 个不同的仓库，导致标签顺序乱七八糟，你是否感到崩溃？
别担心，这个工具就是为你准备的！它能一键将混乱的 PDF 按照 SKU 进行智能分组，并自动从“第1箱”开始为每个 SKU 重新连续排序。
处理后的标签文件逻辑清晰，你只需要直接发给工厂，工人就能按顺序傻瓜式贴标，完全不需要反复沟通确认。（完美适配将不同目的地的货物统一交给同一个货代发货的场景！）
